# Lab 05 — Textures

**Based on learnopengl.com:** [Textures](https://learnopengl.com/Getting-started/Textures)

## Objectives

- Map an image onto a shape with **texture coordinates**.
- Choose **texture wrapping** and **texture filtering**, and understand **mipmaps**.
- Load an image, create an OpenGL texture and **sample** it in the fragment shader.
- Combine two textures with **texture units** and `mix()`.

## Theory

**Texture coordinates** (s, t) run from (0, 0) at the bottom-left of the image to (1, 1)
at the top-right. Each vertex gets one; the fragment shader samples the texture at the
interpolated coordinate: `texture(sampler, TexCoord)`.

**Wrapping** — what happens outside 0..1:

| Mode | Result |
|---|---|
| `GL_REPEAT` (default) | the image repeats |
| `GL_MIRRORED_REPEAT` | repeats, mirrored each time |
| `GL_CLAMP_TO_EDGE` | edge pixels are stretched |
| `GL_CLAMP_TO_BORDER` | a fixed border colour |

**Filtering** — which colour to use between texels:
`GL_NEAREST` picks the closest texel (blocky, pixel-art look);
`GL_LINEAR` blends the neighbours (smooth).

**Mipmaps** are pre-shrunk copies of the image (½, ¼, …) used for far-away objects.
`glGenerateMipmap` builds them; `GL_LINEAR_MIPMAP_LINEAR` blends between levels.
Mipmaps only make sense for the *minifying* filter.

**Loading a texture** (learnopengl uses stb_image; we use Pillow):
open the image → **flip it vertically** (images store the top row first, OpenGL expects
the bottom row first) → `glGenTextures` → `glBindTexture` → set wrap/filter →
`glTexImage2D` → `glGenerateMipmap`. This is written out in `textures.py` and reused as
`glutils.load_texture()` afterwards.

**Texture units** let one shader use several textures. Each `sampler2D` uniform is set
to a unit number, and a texture is bound to each unit:

```python
shader.set_int("texture1", 0); shader.set_int("texture2", 1)     # once
glActiveTexture(GL_TEXTURE0); glBindTexture(GL_TEXTURE_2D, container)
glActiveTexture(GL_TEXTURE1); glBindTexture(GL_TEXTURE_2D, face)
```

`mix(a, b, 0.2)` returns 80 % of `a` plus 20 % of `b`.
